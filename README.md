# 🤖 Двухколесный самобалансирующий робот (BalanceBot)

Проект модульного робота-балансировщика (Inverted Pendulum Robot) на базе микроконтроллера ESP32 (Rust) и десктопного пульта управления со сдвоенным осциллографом (C# WPF / .NET).

---

## 🛠 Аппаратная часть (Hardware BOM)

* **Микроконтроллер:** ESP32 DevKit v1 (30-pin, WROOM-32, 2 ядра Xtensa @ 240 МГц).
* **Сенсор ориентации (IMU):** MPU6050 (GY-521), шина I2C @ 400 кГц.
* **Двигатели:** 2x Шаговых двигателя NEMA 17 (17HS4401, 1.8° на шаг, 4 провода).
* **Драйверы моторов:** 2x A4988 (режим 1/16 микрошага = 3200 шаг/об, MS1-MS3 подтянуты к 3.3V).
* **Колеса:** 85 мм внедорожные резиновые шины с муфтами 12 мм → 5 мм.
* **Питание:** LiPo 4S (14.8V – 16.8V) + импульсный DC-DC преобразователь LM2596 (выход строго 5.0V на VIN).
* **Конденсаторы:** 2x 1000 мкФ 35V Low-ESR на силовых шинах VMOT каждого драйвера.

### 📌 Распиновка (Pinout)

| Модуль | Пин ESP32 | Описание |
|---|---|---|
| **MPU6050 SDA** | GPIO 21 | Данные I2C (400 кГц) |
| **MPU6050 SCL** | GPIO 22 | Такты I2C (400 кГц) |
| **Левый STEP** | GPIO 19 | Шаг левого мотора |
| **Левый DIR** | GPIO 18 | Направление левого мотора |
| **Правый STEP** | GPIO 26 | Шаг правого мотора |
| **Правый DIR** | GPIO 25 | Направление правого мотора |
| **Статус LED** | GPIO 2 | Индикатор активного баланса |

## 🚀 Быстрый старт

### 1. Прошивка ESP32 (Rust)
Требуется установленный тулчейн `esp` (через `espup`).

```powershell
cd firmware

# Создать сид-конфиг для домашней сети (при необходимости)
copy wifi_seed.example.json wifi_seed.json

# Прошивка (автоматически пробует по воздуху OTA, при отсутствии откатывается на USB)
cargo run
```

### 2. Запуск приложения управления (C# WPF)
Требуется .NET 9.0 или .NET 10.0 SDK.

```powershell
cd desktop
dotnet run --project BalanceBot.Desktop
```

1. Нажми **«🔍 Поиск»**, чтобы обнаружить робота в сети, или введи IP вручную.
2. Нажми **«Подключить»**.
3. Управляй балансом, двигайся клавишами **WASD** и подстраивай угол на лету клавишами `[` и `]`.
